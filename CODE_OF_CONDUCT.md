# Code of conduct

Be respectful. No harassment, discrimination, personal attacks or doxxing, in issues, pull requests or discussions. Keep feedback about the work, assume good faith, and help newcomers.

Maintainers may edit or remove comments and may block people who break these rules. Report problems through a private security advisory or to the maintainer's contact on their GitHub profile.

Adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org/).
