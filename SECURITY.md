# Security policy

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the Security tab (private advisory), not in a public issue. Include steps to reproduce, the browser and userscript manager, and the version.

I aim to acknowledge reports within 7 days. Only the latest release is supported.

In scope: anything that could expose a user's files or folder access to a page or third party, or run untrusted code through the script. Out of scope: bugs in X, Discord, or the browser.
